# 💰 Expense Tracker App

## 📌 Project Overview
The Expense Tracker App is a Flutter-based mobile application developed to manage personal income and expenses. It helps users record transactions, organize expenses by category, and monitor their current balance.

## 🎯 Objectives
- Track daily income and expenses.
- Calculate total income, total expenses, and current balance.
- Organize transactions by category.
- Add, edit, and delete transactions.
- Select a date for each transaction.
- Provide a simple and user-friendly interface.

## ✨ Features
- **Current Balance:** Displays the available balance.
- **Income Tracking:** Records money received.
- **Expense Tracking:** Records money spent.
- **Transaction Management:** Add, edit, and delete transactions.
- **Categories:** Food, Travel, Shopping, Bills, Education, Entertainment, and Other.
- **Date Selection:** Choose the date of each transaction.
- **Input Validation:** Checks transaction titles and amounts.
- **Transaction History:** Displays transaction details and amounts.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed
- Dart SDK
- Android Studio or Visual Studio Code
- An emulator or a physical device

### Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd expense_tracker
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```

## 📱 How to Use
1. Open the Expense Tracker application.
2. Tap **Add Transaction** to add a new record.
3. Enter the transaction title and amount.
4. Select a category and choose Income or Expense.
5. Select the transaction date.
6. Tap **Add** to save the transaction.
7. View the updated balance and transaction history.
8. Use the menu beside a transaction to edit or delete it.

## 🧮 Balance Calculation
```text
Current Balance = Total Income - Total Expenses
```
